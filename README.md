# 🚀 Jornada Full Stack — Do Zero ao Mercado

Repositório criado para documentar minha evolução prática nos estudos de Engenharia de Software e desenvolvimento Full Stack.

A proposta é evoluir através de projetos progressivos, aplicando os conceitos estudados em situações práticas e registrando essa evolução com Git e GitHub.

## 🛠️ Tecnologias

Ao longo da jornada serão estudadas e aplicadas tecnologias como:

- JavaScript
- Node.js
- TypeScript
- PostgreSQL
- React
- Git e GitHub
- Testes
- Docker

Além das tecnologias, a jornada também aborda conceitos de arquitetura de software, segurança, APIs, bancos de dados e boas práticas de desenvolvimento.
